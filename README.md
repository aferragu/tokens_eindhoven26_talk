# Token budgets for fleets of AI agents — seminar slides

Andres Ferragut (Universidad ORT Uruguay), joint work with Diego Goldsztajn and Fernando Paganini.

Beamer template from the IFIP Performance 2026 talk (`aferragu/performance26_talk`).

## Building

```
pdflatex tokens_talk && bibtex tokens_talk && pdflatex tokens_talk && pdflatex tokens_talk
```

Needs the `libertine` LaTeX package (texlive-fonts-extra).

## Figures (`figuras/`)

Generated by `scripts/make_figures.py` (numpy, scipy, numba):

- `sample_path.tex` — one simulated path of n(t) and x(t), N=20, p=5.2, B=4 (quota mostly in the interior).
- `dominant_rate.tex` — exact explicit decay rate over its square-root approximation (not used in the current deck).
- `throttle_scaling.tex` — P(throttled) vs scaled quota depth, N = 10, 40, 160, 640, from the balance
  equations on a grid in x (Richardson-extrapolated from steps sigma/100 and sigma/200), checked against simulation.
- `decomposition.tex` — throttled vs unthrottled model, conditional law given x > 0 (simulation).

`fig_tradeoff` (quota needed vs refill margin) is unfinished and not in the deck; run it with `python3 make_figures.py tradeoff`.

Run all with `python3 make_figures.py`, or one with `python3 make_figures.py path|rate|scaling|decomp`.
`battery_mid.png` is copied from the Performance talk.
